# KetabPoyandegan | کتاب‌پویندگان

وب‌سایت معرفی کتاب، فیلم و سریال با طراحی سینمایی — مناسب پروژه‌ی کار و فناوری پایه نهم.

## ویژگی‌ها
- طراحی تیره و سینمایی شبیه داشبورد حرفه‌ای + انیمیشن‌های نرم
- پشتیبانی کامل فارسی / انگلیسی
- ۳۰ کتاب با جلد واقعی (Open Library)
- ۴۴ فیلم، سریال و انیمیشن (با پروکسی تصویر برای لود بهتر)
- فیلتر جداگانه **انیمیشن** (۱۰+ عنوان برتر)
- اسکویید گیم، اسپایدرمن، آرکین، اسپیریتد اوی و آثار جدید
- علاقه‌مندی‌ها و پروفایل شخصی (localStorage)
- فیلتر ژانر، جست‌وجو و مرتب‌سازی
- مودال جزئیات برای هر اثر
- لینک تماشا به آپارات

## اجرای سریع
1. فایل ZIP را استخراج کن.
2. وارد پوشه‌ی `KetabPoyandegan` شو.
3. روی `index.html` دوبار کلیک کن **یا** در ترمینال:

```bash
cd KetabPoyandegan
python -m http.server 8000
```

بعد برو به: http://localhost:8000

اینترنت برای نمایش پوسترها و فونت لازم است.

## نکته
- اگر بعضی پوسترها لود نشدن، placeholder زیبا با عنوان نمایش داده می‌شود.
- اطلاعات پروفایل فقط در مرورگر ذخیره می‌شود.
